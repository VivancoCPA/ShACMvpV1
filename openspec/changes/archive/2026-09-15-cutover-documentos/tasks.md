## 6. Verificar el ciclo de vida completo de un Documento (frontend-documentos-cutover-verification)

- [x] 6.1 `POST /api/documents` (AUTOR=`sin.empresa.qa`) → 201, `codigo` generado server-side (`PRC-CD-002`), `estado: BORRADOR`. `GET /api/documents?page=1&pageSize=5` → 200. Verificado vía API directa (sin navegador, ver nota en 5.2).
- [x] 6.2 `PATCH /:id/status {estado: EN_REVISION}` (AUTOR) → 200. El propio AUTOR intentando `{estado: EN_APROBACION}` → 403 "No tenés permiso para aprobar esta revisión" (correcto: docRole AUTOR no tiene `CanApprove` en `EN_REVISION`, solo REVISOR — confirmado en `DocumentPermissionResolver.GetBasePermissions`). El REVISOR asignado (`mono.empresa.qa`) → 200, `EN_REVISION → EN_APROBACION`. **Hallazgo informativo, no bloqueante**: en la primera pasada de esta verificación, el mismo usuario (`multi.empresa.qa`, rol global `JEFE_CALIDAD_SYST`) fue AUTOR y APROBADOR a la vez del documento — `ResolveDocRole` resuelve `AUTOR` antes que el fallback `JEFE_CALIDAD` por rol global (orden documentado en el propio código: "Un JEFE_CALIDAD_SYST asignado como revisor de ESE documento es docRole REVISOR aquí, no JEFE_CALIDAD"), así que ese usuario perdió sus permisos de `JEFE_CALIDAD_SYST` sobre ese documento en particular y no pudo aprobar. Confirmado que es un diseño intencional (replica `getDocRoleForUser` del mock carácter por carácter, mismo comentario en el código), no un bug — se documenta para que quede claro por qué la primera corrida del script de verificación falló con 403 antes de separar los 3 roles en usuarios distintos.
- [x] 6.3 `POST /:id/sign` (APROBADOR=`multi.empresa.qa`) con PIN incorrecto (`0000`) → 401. Con PIN correcto (`4321`) → 200, `estado: PUBLICADO`, `archivoDistribucionUrl` generado (`/uploads/documentos/.../distribucion/v1.0.pdf`) — confirma que el fix del mismatch de contrato (D1) funciona de punta a punta contra el backend real.
- [x] 6.4 `PATCH /:id/status {estado: BORRADOR, motivo (≥20 chars), notificarAutor: true}` (REVISOR asignado) → 200, documento vuelve a `BORRADOR`.
